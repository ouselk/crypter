
Консольное приложение на **C++17** для шифрования и дешифрования текстовых данных с использованием различных криптографических алгоритмов.

## Возможности

* 🔐 Авторизация по паролю
* 📝 Ввод текста через встроенный редактор
* 📂 Загрузка текста из файла
* 🔒 Шифрование текста
* 🔓 Дешифрование текста
* 💾 Сохранение результатов в `.txt`
* 🔑 Работа с ключами шифрования
* 🛡️ Проверка пароля и защита от перебора

## Поддерживаемые шифры

* Шифр со сдвигом по кодовому слову
* Простой табличный шифр
* Шифр Виженера
* RSA
* Шифр Гронсфельда
* Атбаш

Программа поддерживает работу с русским и английским алфавитами, а также символами расширенной **ASCII-1251**.

## Технологии

* **C++17**
* **Microsoft Visual Studio 2022**
* **Windows**

## Структура проекта

* `main.cpp` — главный модуль программы
* `crypt.cpp / crypt.h` — алгоритмы шифрования
* `funcs.cpp / funcs.h` — вспомогательные функции
* `files.cpp / files.h` — работа с файлами
* `userInterface.cpp / userInterface.h` — пользовательский интерфейс

## Запуск

Программа предназначена для работы в среде **Windows**.

После запуска необходимо указать файлы для исходного и зашифрованного текста, выбрать режим шифрования/дешифрования и нужный алгоритм.
